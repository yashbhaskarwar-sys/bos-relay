# BOS Relay

Operational Bridge · Bhaskarwar-OS · V1.7

A single static HTML file that shows the operator exactly where they are, what project is active, what the next action is, and which tool to open — in under 30 seconds.

## What it is

BOS Relay is a lightweight visible operational bridge for solo operators working across multiple projects and tools. It is not a dashboard, planner, or productivity system. It is a re-entry surface: open it, read it, begin.

## How to use

1. Open `relay.html` in any browser
2. Bookmark it (Cmd+D) for one-click daily access
3. At the end of every session: open in any text editor, update `state`, `next`, and `updated` for the project you worked on, save, refresh

## Architecture

- Single self-contained HTML file
- No dependencies, no frameworks, no backend
- Operator-editable JavaScript data block
- Offline-first, local-first, operator-owned
